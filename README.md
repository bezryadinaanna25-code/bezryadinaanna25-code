## 24 собственных ИИ-инструмента

Повторяющиеся процессы двух проектов вынесены в отдельные инструменты:

**реклама → отчётность → сайты → контент → команда**

Они вызываются обычными командами на русском языке — например:  
`«подбери каналы»` · `«сделай план-факт»` · `«создай страницу юриста»`

Главная идея: знания о процессе хранятся не в голове и переписках, а в воспроизводимой рабочей системе.
